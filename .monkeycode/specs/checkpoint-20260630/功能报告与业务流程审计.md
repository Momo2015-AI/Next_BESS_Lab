## 1. 项目概述

SOH-SIM (储能电站 SOH 仿真计算系统) 是一个面向 BESS 投标技术支撑的全栈 Web 应用。系统按 5 个 Phase 逐层推进：项目设定 -> 系统设计 -> 性能仿真 -> 财务分析 -> 交付物导出。另附 12 个独立工具模块（公式实验室、参数管理、工程计算等）。

技术栈：后端 Flask + SQLite，前端 Vue 3 + Pinia + Vite。

### 2.3 管线计算流程 (Pipeline)

```
用户输入
  │
  ├── systemParams (温度/充放倍率/循环数/DOD/设备规格)
  ├── algorithm (模型类型/修正因子/GB曲线/环境因子)
  ├── degradation (可选预计算SOH/RTE/DOD/增容方案)
  └── financial (CAPEX/OPEX/收入/融资/税务)
          │
          ▼
  calculate_full_pipeline()
     ├─ 1. predict_soh() → SOH[26], RTE[26]
     ├─ 2. calculate_energy_accounting() → 初始AC可用 + 逐年增容 + 需求满足判定
     ├─ 3. calculate_efficiency_curves() → 效率链26年曲线
     └─ 4. calculate_financial_metrics() → IRR/NPV/LCOE/DSCR/回本
          │
          ▼
  返回统一结果: {soh, rte, dod, initGross, augAcUsable, totalAcUsable, meetsReq, financial, efficiencyCurves}
```

### 2.4 后端遗留代码

`app.py:64-163` 包含一个旧版 `calculate()` 函数，功能与 `services/pipeline.py:calculate_energy_accounting()` 重复但缺少效率链集成。旧版由 `/api/soh/calculate` 端点调用，新版经由 `/api/pipeline/calculate`。两套代码**需合并清理**。
