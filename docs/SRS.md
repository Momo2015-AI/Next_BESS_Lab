## 1. 引言

### 1.1 编写目的
本文档详细描述储能电池健康状态（SOH）仿真系统的功能需求、非功能需求、系统架构和接口规范，为开发团队提供明确的开发指导，为测试团队提供测试依据，为项目干系人提供需求确认依据。

### 1.2 项目背景
储能系统（BESS）是新能源领域的重要组成部分，电池的健康状态（SOH）直接影响系统的性能和经济效益。本项目旨在开发一个基于阿伦尼乌斯衰减模型的SOH仿真计算系统，帮助工程师评估电池在不同工况下的寿命表现，支持参数配置、计算、可视化、多场景对比和结果导出。

### 1.3 适用范围
本文档适用于以下人员：
- 产品经理：确认需求范围和优先级
- 开发团队：理解需求、设计系统、编写代码
- 测试团队：编写测试用例、验证功能
- 运维团队：部署系统、监控系统
- 客户：了解系统功能和使用方式

### 1.4 术语和定义

| 术语 | 定义 |
|------|------|
| SOH (State of Health) | 电池健康状态，表示电池当前容量与额定容量的比值 |
| DOD (Depth of Discharge) | 放电深度，表示电池放电量与额定容量的比值 |
| RTE (Round-Trip Efficiency) | 往返效率，表示电池充放电循环的能量效率 |
| BESS (Battery Energy Storage System) | 电池储能系统 |
| 阿伦尼乌斯模型 | 用于描述电池老化速率与温度关系的数学模型 |
| 日历老化 | 电池在静置状态下的容量衰减 |
| 循环老化 | 电池在充放电循环中的容量衰减 |

## 2. 总体描述

### 2.1 系统目标
提供一个专业的储能电池健康状态仿真计算平台，支持：
- 基于阿伦尼乌斯模型的SOH衰减计算
- 灵活的参数配置和场景对比
- 直观的可视化图表展示
- 财务投资分析
- 报告生成和导出

### 2.2 用户特征

| 用户角色 | 描述 | 主要需求 |
|----------|------|----------|
| 仿真工程师 | 使用系统进行电池寿命仿真分析 | 参数配置、计算、结果可视化 |
| 项目经理 | 管理项目、查看仿真结果、生成报告 | 项目管理、报告导出 |

### 3.2 SOH计算模块 (R2)

#### 3.2.1 单场景SOH计算
**需求ID**：R2-1
**优先级**：高
**描述**：基于阿伦尼乌斯模型计算电池25年生命周期内的SOH衰减曲线

**输入**：参数配置对象（见3.1节）

**输出**：
```json
{
  "years": [0, 1, 2, ..., 25],
  "soh": [100, 98.5, 97.0, ..., 80.0],
  "rte": [97.03, 96.8, 96.5, ..., 94.0],
  "capacity": [1000, 985, 970, ..., 800],
  "netAvailable": [950, 935, 920, ..., 760]
}
```

**计算公式**：
```
日历老化：Q_cal(t) = A_cal × exp(-Ea_cal / (R × T)) × t^alpha
循环老化：Q_cyc(N) = A_cyc × exp(-Ea_cyc / (R × T)) × N^beta × DOD_factor × C_rate_factor
总衰减：SOH(t) = 1 - (Q_cal(t) + Q_cyc(N(t)))
```

**性能要求**：
- 计算响应时间 < 1秒
- 支持25年数据点（26个数据点）

#### 3.2.2 多场景对比计算
**需求ID**：R2-2
**优先级**：高
**描述**：支持同时计算多个场景，便于对比分析

**输入**：参数配置数组

**输出**：多个场景的计算结果数组

#### 3.2.3 算法参数配置
**需求ID**：R2-3
**优先级**：中
**描述**：用户可以调整阿伦尼乌斯模型的参数

**可配置参数**：
| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| A_cal | number | 0.02 | 日历老化系数 |
| Ea_cal | number | 20000 | 日历老化活化能 (J/mol) |
| alpha | number | 0.8 | 日历老化时间指数 |
| A_cyc | number | 0.001 | 循环老化系数 |
| Ea_cyc | number | 15000 | 循环老化活化能 (J/mol) |
| beta | number | 0.5 | 循环老化次数指数 |

### 3.7 财务分析模块 (R7)

#### 3.7.1 财务指标计算
**需求ID**：R7-1
**优先级**：高
**描述**：计算储能项目的财务指标

**计算指标**：
| 指标 | 说明 |
|------|------|
| NPV | 净现值 (Net Present Value) |
| IRR | 内部收益率 (Internal Rate of Return) |
| LCOE | 平准化度电成本 (Levelized Cost of Energy) |
| ROI | 投资回报率 (Return on Investment) |
| DSCR | 偿债覆盖率 (Debt Service Coverage Ratio) |
| 回收期 | 投资回收期 (Payback Period) |

**收入模型**：
```
总收入 = 套利收入 + 容量市场费用 + 辅助服务费
```

**成本模型**：
```
总成本 = CAPEX + OPEX
CAPEX = 集装箱成本 + PCS成本 + BOP成本 + 开发费用
OPEX = 固定运维 + 可变运维 + 保险 + 土地租金
```
