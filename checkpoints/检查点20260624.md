### 2.3 企业隔离（多租户）实现

```
所有产品表均含 tenant_id + is_builtin 字段：
  ├─ is_builtin=True, tenant_id=None  → 系统内置，所有企业可见
  ├─ is_builtin=False, tenant_id=X    → 企业X专有，仅本企业+超管可见
  └─ 超级管理员(role=admin)            → 可见全部数据

_apply_tenant_filter() 统一过滤逻辑：
  query.filter(or_(model.tenant_id == user.tenant_id, model.is_builtin == True))
```

### 4.4 PCS 配置原则（本次修正后）

```
totalPower = container.power × containerQty  ← 使用额定功率，不再取 max
pcsQty = Math.ceil(totalPower / pcs.power)

示例：
  10 × 5MWh/2.5MW 集装箱 → totalPower = 25MW
  选择 2.5MW PCS → pcsQty = ceil(25/2.5) = 10台（1:1 配对）
  选择 1.725MW PCS → pcsQty = ceil(25/1.725) = 15台
```

### 4.5 BESS 辅助功耗计算流程（本次新增）

```
┌── 参数输入 ──────────────────────────────────────────┐
│  运行策略：天数/循环/时长                                │
│  效率拓扑：DC-RTE / PCS效率 / AC效率                     │
│  辅助功率：舱运行/待机 + PCS运行/待机 + 站宇固定          │
└────────────┬─────────────────────────────────────────┘
             │
             ▼
┌── 核心公式 ──────────────────────────────────────────┐
│  tRun = days × cycles × hours × 2                     │
│  tStd = days × 24 - tRun                              │
│  DC辅耗 = [(tRun×bRun) + (tStd×bStd)] × units / 1000 │
│  AC辅耗 = [(tRun×pRun) + (tStd×pStd) +               │
│           (days×24×pStation)] / 1000                  │
│  总辅耗 = DC辅耗 + AC辅耗                               │
│  毛放电量 = cap × units × √RTE × cycles × days        │
│           × acEff × pcsEff                             │
│  净放电量 = 毛放电量 - 总辅耗                            │
└────────────┬─────────────────────────────────────────┘
             │
             ▼
┌── 展示 ────────────────────────────────────────────┐
│  AuxPowerCalculator（仪表盘+参数+公式沙盒）             │
│  FormulaLab（内嵌辅耗计算器，参数可编辑联动）            │
│  AlgorithmLab（算法模型展示）                           │
└──────────────────────────────────────────────────────┘
```
